
# 网页摘要与笔记收集器（Chrome 扩展）

点开任意网页，用 LLM 生成 **子弹笔记形式**的 ~100 字摘要和最多 **3 个关键字**，可手动增删关键字、写阅读感想，一键把记录写入飞书多维表格（Bitable）。飞书表即唯一存储。还可以右键选中网页中的任意段落，直接保存为"段落"类型，并附加你的想法。

## 功能特性

- 📄 抓取当前页面 URL + 标题 + 正文（轻量去噪提取，支持 Markdown 格式）
- 🪄 LLM 生成**子弹笔记式摘要**（一级 `•`、二级 `◦`、三级 `—`）+ 最多 3 个关键字
- 📝 关键字可手动增删、感想自由填写
- 💾 一键保存到飞书多维表格
- 🎯 **摘要按文章类型收尾**：
  - 评论型 → 末尾 `■ 总结：`
  - 操作型 → 末尾 `■ 建议：`
- ✂️ **右键菜单**：选中任意段落 → 右键"保存为段落" → 弹出对话框输入想法 → 直接保存到飞书

## 支持的 LLM 厂商（可切换）

API Key 仅存本地 `chrome.storage.local`，不上传任何服务器。

| 厂商     | 默认模型      | 获取 Key                              |
| -------- | ------------- | ------------------------------------- |
| DeepSeek | deepseek-chat | https://platform.deepseek.com/        |
| 智谱 GLM | glm-5.1       | https://open.bigmodel.cn/             |
| 通义千问 | qwen-turbo    | https://dashscope.console.aliyun.com/ |

> 厂商出新模型不用等代码更新：设置页「模型」字段是可自由输入的（带建议项），填入新 model id 即可。

## 安装

1. 打开 `chrome://extensions`
2. 右上角开启「**开发者模式**」
3. 点「**加载已解压的扩展程序**」→ 选择本项目根目录 `chrome_plugin_highlight/`
4. 工具栏出现扩展图标
5. 首次加载后，进入扩展**详情页**，把「**网站访问权限**」设为「**在所有网站上**」（manifest 声明了 `<all_urls>` 注入权限）

> 本扩展为纯前端实现，无需安装任何本地脚本或后端服务。

## 配置

点扩展图标打开侧边栏，点右上角 ⚙ 进入设置页。

### 1. LLM 配置

- 选择厂商
- 填入对应厂商的 API Key
- 模型可留空（用默认）或自己填 model id
- 点「**测试连接**」验证 Key 与网络是否通

### 2. 飞书多维表格配置

⚠️ **重要前提**：本扩展需要飞书应用作为多维表格的「可编辑」协作者。**飞书个人版（含「个人企业」版）目前不支持应用作为多维表格协作者**，必须使用飞书企业版（团队租户，可个人注册免费版）。

#### 步骤 1：注册飞书企业版

- 用浏览器无痕窗口打开 https://feishu.cn → 注册个人企业（一个人就是一家公司，免费）
- 创建完成后进入企业版工作台

#### 步骤 2：建自建应用

- 进入 https://open.feishu.cn/app →「**创建企业自建应用**」→ 命名
- 「**凭证与基础信息**」：复制 **App ID** 和 **App Secret** 到扩展设置页
- 「**权限管理**」：搜「多维表格」→ 勾选 `bitable:app`（读写）
- 「**应用能力**」：开启「**机器人**」
- 「**版本管理与发布**」：创建版本 → 发布

#### 步骤 3：建多维表格

在企业版里新建多维表格，按下表建 **8 列**（列名**必须一字不差**）：

| 列名   | 字段类型 | 说明                            |
| ------ | -------- | ------------------------------- |
| 标题   | 多行文本 | 网页标题                        |
| URL    | 多行文本 | 网页地址                        |
| 类型   | 多行文本 | 文章 / 段落                     |
| 摘要   | 多行文本 | 子弹笔记形式，约 100 字         |
| 关键字 | 多行文本 | 分号连接，最多 3 个             |
| 原文   | 多行文本 | 页面正文（Markdown 格式）       |
| 感想   | 多行文本 | 用户填写的阅读感想              |
| 时间戳 | 多行文本 | 本地时间`YYYY-MM-DD HH:MM:SS` |

> URL 列**不要**选「链接」类型，会写入失败。
> 列名多一个空格、少一个字都会写入失败——具体怎么排错见下文。

#### 步骤 4：把应用加进表格

- 打开这个多维表格 → 右上角「...」→「**文档权限**」→「**管理协作者**」→ 「**添加协作者**」
- 搜索企业版下创建的应用名 → 添加 → 权限「**可编辑**」

#### 步骤 5：取 App Token 和 Table ID

浏览器地址栏 URL 形如：

```
https://my.feishu.cn/base/YC17bwgCMaCGUfsWgbNcWTuan0f?table=tbloU6RyH1wRkvHj&view=vewd3KQrsB
                       ↑ App Token                  ↑ Table ID
```

- **App Token** = `/base/` 后那段（通常以 `BAS` 或随机字符开头）
- **Table ID** = `table=` 后那段（通常以 `tbl` 开头）

填进扩展设置页 → 点「**测试连接**」→ 提示「字段齐全 ✓」即完成。

## 使用

### 方式 1：生成摘要（完整流程）

1. 打开任意网页
2. 点工具栏扩展图标，侧边栏自动打开，显示当前页面标题 + URL
3. 点「**生成摘要与关键字**」→ LLM 返回子弹笔记摘要 + 最多 3 个关键字 + 页面原文（Markdown 格式）
4. 按需编辑摘要 / 增删关键字 / 写感想
5. 点「**保存到飞书**」→ 记录已写入飞书表（类型为"文章"）

> 切到其他标签再回来时，顶部信息会自动更新。

### 方式 2：快速保存段落（右键菜单）

1. 在任意网页上选中一段文本
2. 右键点击 → 选「**保存为段落**」
3. 弹出对话框，显示选中的文本
4. 在"你的想法"框里输入当时的想法（可选）
5. 点「**保存**」→ 直接保存到飞书（类型为"段落"）

## 调试与常见问题

### 测试连接提示「表里缺少列」

飞书表实际列名和代码期望的不一致。在设置页点「测试连接」，错误信息会：

- 列出**完全不存在的列**（`missing`）
- 用模糊匹配提示**含空格/不可见字符的差异**（`suggestions`）
- 把**飞书表实际列名全部列出**（`existing`）

按 `existing` 那段复制对比，对齐即可。

### 生成摘要失败：无法读取当前页面内容

- 系统页面（`chrome://`、`chrome-extension://`、本地 `file://`）无法注入，换普通网页
- 扩展首次安装后，确认 `chrome://extensions` 详情页「网站访问权限」设为「在所有网站上」

### 保存失败：飞书获取字段失败 (99991672)

应用权限未开通或未发布：

1. 开放平台 → 应用 → 「权限管理」→ 确认勾选 `bitable:app`
2. 「版本管理与发布」→ 创建新版本并发布

### 保存失败：飞书写入失败 (91403 Forbidden)

应用未加为表格协作者或权限非「可编辑」：

1. 多维表格 → 「...」→「文档权限」→「管理协作者」→ 确认应用在列表中且权限为「可编辑」

### 保存失败：FieldNameNotFound (1254045)

飞书表里的列名与代码期望的不一致。回到设置页点「测试连接」对比实际列名。

### 时间戳显示不对

时间戳是**本地时区**（你电脑系统时区），不是 UTC。如需 UTC 可改 `src/background.js` 里的日期生成逻辑。

### 清缓存

```js
chrome.storage.local.remove('__feishu_token_cache__');
```

在扩展详情页的「service worker」控制台执行。

## 文件结构

```
chrome_plugin_highlight/
├── manifest.json
├── src/
│   ├── background.js                    # service worker：消息路由 + 编排
│   ├── lib/
│   │   ├── extract.js                   # 页面正文提取 → Markdown 格式
│   │   ├── llm.js                       # 多厂商 LLM 适配（含模型字段可自由输入）
│   │   └── feishu.js                    # 飞书 Bitable 接入（含字段模糊匹配）
│   ├── sidepanel.html/.css/.js          # 侧边栏主界面
│   ├── options.html/.css/.js            # 设置页
│   ├── quote-dialog.html/.js            # 右键菜单段落保存对话框
│   └── sidepanel.css                    # 侧边栏样式
├── icons/                               # 16 / 48 / 128 占位图标
├── test/
│   └── e2e.mjs                          # Playwright 回归脚本
├── DESIGN.md                            # 产品设计文档
└── README.md                            # 本文档
```

## 开发与回归测试

`test/e2e.mjs` 是 Playwright 端到端冒烟测试，覆盖扩展加载、options/side panel UI、配置保存、按钮状态联动、错误路径。改完代码后跑：

```bash
node test/e2e.mjs
```

> 自动化模拟不了「点图标打开 side panel」授予 activeTab，抓正文 + LLM 真链路留真实环境验证。

## 数据安全

- API Key 与飞书凭据仅存在本地 `chrome.storage.local`，不上传任何第三方服务器
- LLM 请求由浏览器直连对应厂商，飞书写入直连飞书开放平台
- 不依赖任何后端服务，单文件即可分发
